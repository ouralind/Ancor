## 🔍 Направления тестирования

- **Функциональное тестирование** — проверка новой и существующей функциональности на соответствие требованиям.
- **Регрессионное тестирование** — проверка ранее реализованного функционала после изменений.
- **Исследовательское тестирование** — исследование продукта и поиск дефектов за пределами основных сценариев.

## 🛠️ Задачи

- Выполнение подготовленных тестовых сценариев.
- Выявление, воспроизведение и документирование дефектов.
- Проверка корректности работы новой и существующей функциональности.
- Ретест исправлений и проведение регрессионных проверок.
- Взаимодействие с командой разработки по вопросам обнаруженных дефектов.
- Работа с полным циклом обработки дефектов: от обнаружения до проверки исправления.
